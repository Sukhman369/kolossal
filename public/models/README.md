# 3D Models Directory for Kolossal

Drop your 3D `.glb` or `.gltf` model here as:
`hero-garment.glb`

When this file is present, `Hero3DScene.tsx` will automatically detect and load your custom 3D model with realistic studio environment lighting, floating animations, and drag rotation.

If no file is present, the hero automatically displays the procedural sculpted chrome emblem.
